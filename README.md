# 물류창고 신규 입사자 온보딩 가이드 문서 체계 설명서

---

## 1. 개요 및 목적
본 저장소(`test-01`)는 물류센터에 처음 입사한 작업자 및 실무 담당자가 현장 업무에 안전하고 신속하게 적응할 수 있도록 제작된 **표준 실무 온보딩 매뉴얼**을 관리합니다.

전체 매뉴얼은 7개의 핵심 챕터로 분할되어 관리되며, 이론 중심이 아닌 현장에서 즉시 적용 가능한 체크리스트, 다이어그램, 트러블슈팅 매뉴얼을 포함하고 있습니다.

---

## 3. 문서 활용 권장 가이드

1. **신규 입사자 교육 (Day 1 ~ Day 2)**:
   - `01_회사소개_및_센터개요.md`와 `02_현장안전수칙_및_EHS.md`를 필독하여 센터 레이아웃과 안전 규정을 숙지합니다.
2. **현장 실무 OJT (Day 3 ~ Day 4)**:
   - 본인이 배정된 공정(입고/적재는 `03번`, 출고/피킹/패킹은 `05번`) 문서를 숙독하고, 공통 도구인 `06_WMS_및_PDA_활용법.md`를 실습합니다.
3. **업무 정착 및 주기적 점검 (Day 5 이후)**:
   - `04_보관_및_재고관리.md`의 로케이션 원칙과 `07_조직문화_근태_및_에티켓.md`의 5S 마감 루틴을 체화합니다.

## 4. 기여 및 문서 업데이트 가이드라인
- 현장 설비 도입(자동화 소터, AGV 등)이나 프로세스 변경 시 해당 챕터 문서를 업데이트합니다.
- Git 협업 시 `main` 브랜치에 직접 커밋하기보다는 `feat/<기능명>` 또는 `docs/<문서명>` 브랜치를 생성한 후 풀 리퀘스트(PR)를 통해 반영하는 것을 권장합니다.
